기본값
기본 마나재생량 : 1/100초
기본 구호품 주기 : 40초
기본 구호품 생존시간 : 60초
기본 구호품 보상 : 1~12 중 무작위 × 0.5(어묵 제외)
기본 스킬 시간 : 5분
기호 설명
D : 스킬(버프) 유지시간
R : 필요 마나 소모율
T_f, u : 구호품 소비주기 계산용 중간값
P : 구호품 실제 소비주기(획득 주기)
E : 구호품 1회 평균 획득량
I : 구호품 마나 수급률
S : 총 마나 수급률
cost_i, D_i : i번째 스킬의 필요마나·유지시간
자연 마나 회복량(초당) = 0.6 × (1 + 흑요석×0.1) / 60
버프 유지시간 D = 300 × (1+스킬 유지시간%) / (부스터 ? 2 : 1)
필요 마나 소모율 R = Σ (cost_i / D_i)
T_f = 2000 / 고철, u = (T_f − 40) mod 100
소비주기 P = 40 (T_f<40) | T_f (u≤60) | T_f+(100−u) (그 외)
E = 0.5 × ( Σraw=1..12 floor(raw×(1+구호품 보상%)) / 12 )
구호품 수급률 I = E / P
총 수급률 S = 자연회복량 + (기준≠구호품X ? I : 0)
성공 조건: S > R
회당시간효율_i = D_i − cost_i / (S − (R − cost_i/D_i))
회당마나효율_i = (S − (R − cost_i/D_i)) × D_i − cost_i
탐색: min max(고철,흑요석) s.t. S>R, tie-break: 흑요석 asc → 고철 asc
포션 계산 방식 (필요한 포션 개수)
마나 캡 = 100, 시작 마나 = 0 (지금 켜진 버프들 시전하는 데 이미 다 씀)
자연 마나: 매 순간 연속으로 흐름(자연 마나 회복량만큼)
구호품 마나: P초마다 한 번 E만큼 뭉텅이로 지급(이산 이벤트) — 마나가 100 넘으면 초과분은 버려짐(캡)
마나가 100이 되는 순간: 켜진 스킬 중 남은 버프시간이 가장 짧은 스킬이 자동 재시전(무료)
스킬 버프가 끝나는 순간: 마나가 cost_i 이상이면 자동 재시전(무료)
재시전은 리셋이 아니라 스택: 남은 버프시간 += D_i
위 두 자동 조건이 모두 실패(버프 종료 시점에 마나 부족)할 때만 포션으로 부족분을 채우고 수동 시전 처리, 그때마다 필요한 포션 개수 누적
방치할 시간이 끝난 시점 잉여 버프시간이 D_i 초과면 "+HH:MM:SS 이득!", 아니면 "수동 시전 n번(누적시간)"으로 표시
